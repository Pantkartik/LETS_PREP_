# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Multi-language code execution support (JavaScript, Python, Java, C++)
- Real-time code validation with Docker backend
- Optimized code execution performance (70-90% faster)
- Authentication token integration for backend API
- Parallel test case execution
- Complexity analysis for all languages
- Celebration animations on successful submissions
- User statistics tracking
- Problem workspace with premium UI/UX

### Changed
- Improved loading speed for problem workspace
- Enhanced error handling with silent fallbacks
- Optimized UI with immediate feedback
- Non-blocking stats updates

### Fixed
- Backend authentication 401 errors
- Console error on backend fallback
- Infinite loading states
- Async params handling in Next.js 15

## [1.0.0] - 2026-01-31

### Added
- Initial production release
- LeetCode-style problem workspace
- Multi-language IDE with Monaco Editor
- Real-time code execution engine
- User authentication with Supabase
- Teacher dashboard for battle rooms
- Student analytics and progress tracking
- Problem library with difficulty levels
- Battle room system for competitive coding
- Real-time leaderboards
- Profile management
- Dark mode UI with glassmorphism

### Security
- Environment variable protection
- Authentication middleware
- Rate limiting on API endpoints
- Secure Docker code execution

## Version History

### Version Format: MAJOR.MINOR.PATCH

- **MAJOR**: Breaking changes
- **MINOR**: New features (backward compatible)
- **PATCH**: Bug fixes (backward compatible)

### Categories

- **Added**: New features
- **Changed**: Changes in existing functionality
- **Deprecated**: Soon-to-be removed features
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Security**: Security improvements
